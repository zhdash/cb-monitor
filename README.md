# cb-monitor · 可转债成交额监控

A 股可转债的**日内资金博弈监控面板**：从全市场按成交额取前 20，实时跟踪 5 分钟 / 60 分钟两个周期的下跌形态，自动入池与剔除，并记录每一次进出的原因与数值。

> 面向日内交易者：只看波动、换手与资金节奏，不做长期持有判断。

## 功能

**① 全市场明细表**
按成交额排序，展示前 20 的：现价、涨跌幅、成交额、**溢价率**、成交量、最高、最低，支持点击查看 K 线、勾选自选。已公布强赎的债会打「强赎」小标（悬停显示公告日 / 赎回登记日 / 赎回价）。

**② 「5下跌」池** —— 5 分钟规则，**只认已收盘 K 线**，每 10 秒扫描

| | 规则 |
|---|---|
| 入池 | 从最新一根已收盘 K 线往前，一路不出现上涨（收 ≤ 前收，**走平不算中断**），这段里**有 2 根单根跌超 0.25%**（不要求相邻） |
| 排序 | 按「跌超 0.25%」的**根数降序**，显示「连跌达标 N 根」 |
| 剔除 ① | **涨破**：任一根已收盘 K 线 收 > 前收 |
| 剔除 ② | **破位**：入池之后、且 ≥10:15 的已收盘**下跌** K 线，其**最低价** ≤ 入池时日内低点 ×(1+0.05%) |
| 剔除 ③④⑤ | 掉出成交额前 20 / 已公布强赎 / 手动移除 |

> 破位只认**最低价**，不要求收盘价也在新低；基准取「入池那一刻已确定的日内低点」——取样点那根 K 线在入池时还在走，**不计入基准**，否则会用未来数据把基准追低、导致永不剔除。

**③ 「60下跌」池** —— 60 分钟规则，**不等收盘**，每 1 分钟复核

三条门槛需同时满足（全部实时）：
1. 最新一根 60 分钟 K 线本根累计跌幅 **≥ 1.9%**
2. 当天**没碰过、也没跌到** 60 分钟布林中轨下方（`low ≤ mid`）
3. 当天除第一根外，没有「下跌 K 线」触及当天最高价（`high ≥ 当天最高 ×(1−0.05%)`）

> 第一根（10:30）常是当天最高点来源，不参与第 3 条检查。

**④ 进出流水**
独立卡片记录最近 40 条入池 / 剔除（时刻 + 名称 + 原因 + 判定数值），localStorage 持久化。剔除往往是瞬时发生的，事后根本看不见，有它才能当场核对「谁 / 几点 / 因哪条规则 / 当时数值多少」。

**⑤ 收盘后自动暂停扫描**
行情状态为「已收盘 / 休市」时跳过自动扫描（手动「立即」按钮不受影响），避免收盘后 K 线不再变化导致的无效空转。

## 运行

```bash
python app.py          # 默认端口 8011
```

浏览器打开 <http://127.0.0.1:8011>。Windows 可双击 `start.bat`。

无需安装第三方依赖，只用标准库。

## 文件说明

| 文件 | 说明 |
|---|---|
| `app.py` | **入口**。增强启动器：gzip、vendor 强缓存、首页指向 `app.html`，并新增 `/api/klines60`、`/api/premium`、`/api/redeem` 三个接口 |
| `app.html` | 美化版前端页面（实际使用的页面） |
| `server.py` | 数据源 / 连接池 / 缓存 / 基础 API，被 `app.py` 在运行时打补丁扩展 |
| `index.html` | 早期版本页面，保留作参考；`app.py` 在找不到 `app.html` 时回退到它 |
| `vendor/echarts.min.js` | K 线图表库（本地托管，24h 强缓存） |
| `start.bat` | Windows 启动脚本 |

## 数据源

| 用途 | 来源 |
|---|---|
| 实时行情 | 腾讯 `qt.gtimg.cn` |
| 5 / 60 分钟 K 线 | 腾讯 `ifzq.gtimg.cn` / `mkline` |
| 转股溢价率 | 东方财富 `push2/qt/ulist.np/get`（按代码分 3 批，缓存 60s） |
| 强赎名单 | 东方财富 `RPT_BOND_CB_LIST` |

> 溢价率接口部分字段（`TRANSFER_VALUE` 等）为**初始值且不更新**，本项目取的是 `f235` 当期转股价 / `f236` 转股价值 / `f237` 溢价率。

## 接口

| 路径 | 说明 |
|---|---|
| `/api/quotes` | 批量实时行情 |
| `/api/klines` | 批量 5 分钟 K 线 |
| `/api/kline` | 单只 K 线 |
| `/api/klines60` | 批量 60 分钟 K 线 |
| `/api/premium` | 全市场转股溢价率 |
| `/api/redeem` | 已公布强赎名单 |

## 说明

- 两池**共同铁律**：只收「成交额前 20」，掉出即剔；**已公布强赎的债一律不收**。
- 判定**只用原始价格、不加容差**（涨 0.001 元也算涨）。显示层对微涨微跌保留 4 位小数并标注【涨 / 平 / 跌】，避免把「显示成 0.00%」误当成「没涨」。
- 本工具仅做数据整理与条件提示，**不构成任何投资建议**。
